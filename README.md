# CSIDE 타찾 대시보드

타찾 명단을 개강월, 주차, 팀, 구역, 섭외유형별로 비교하는 로컬 대시보드입니다. 개강월별 그래프에서 1–12월을 선택할 수 있고, 팀을 선택하면 구역별 상세 집계가 열립니다.

## 실행

Node.js 22.9 이상에서 저장소 폴더를 연 뒤 실행합니다. 설치할 패키지는 없습니다.

```sh
npm start
```

브라우저에서 `http://127.0.0.1:4173`을 엽니다. PowerShell의 실행 정책 때문에 `npm` 실행이 차단되면 `npm.cmd start`를 사용하세요.

## 타찾 명단 반영

Google Sheets에서 타찾 명단 탭을 선택하고 **파일 → 다운로드 → 쉼표로 구분된 값(.csv)**으로 저장합니다. 대시보드의 **데이터 관리 → 타찾 명단 CSV 가져오기**에서 파일을 선택합니다. 여러 파일을 한 번에 추가할 수 있고, 동일한 탭 이름으로 다시 가져오면 그 탭의 집계가 갱신됩니다.

- 새 주차는 `타찾 2월3`, `타찾 12월 10주차`처럼 개강월과 주차를 탭 이름에 넣습니다. 괄호로 된 기수 표기도 읽습니다.
- 첫 행에 `팀-구`, `섭외유형`, `특이사항` 열을 둡니다. `1-2`는 1팀 2구역입니다.
- 섭외유형이 기입된 명단 행을 집계합니다. `정파만남` 표시가 들어간 행은 제외하고, `개척` 유형은 개척지인에 합칩니다. 정의된 나머지 유형에 속하지 않는 값은 기타에 포함합니다.
- 월은 개강월 기준입니다. 등록된 탭이 없는 달은 자료 없음으로 표시합니다.

## Google Sheets 직접 연결

Google Cloud에서 Sheets API를 활성화하고, 읽기용 서비스 계정에 원본 스프레드시트의 **뷰어** 권한을 부여합니다. 저장소 루트에 `.env`를 만들고 Sheet URL의 문서 ID와 서비스 계정 키 파일 경로를 설정합니다.

```dotenv
GOOGLE_SHEETS_ID=스프레드시트_문서_ID
GOOGLE_APPLICATION_CREDENTIALS="C:/private/sheets-viewer.json"
```

다시 실행하면 처음 열 때 Sheets를 확인하고, **데이터 관리 → Google Sheets 새로고침**으로 바로 갱신할 수 있습니다. 규칙에 맞는 이름으로 추가한 명단 탭도 자동으로 집계됩니다. 갱신에 실패하면 마지막 로컬 집계를 표시합니다. 직접 연결을 켠 경우 시트가 집계의 원본이 됩니다.

집계 파일은 로컬 `.data/`에 저장합니다. 이름, 만남날짜, 특이사항 원문은 저장하지 않습니다. 서비스 계정 키 파일은 저장소 밖에 둡니다.

```sh
npm test
```
