## Website feedback recorded on 2026-09-16

Apply to future website, UI and development work. Update with later user corrections.

- Keep titles and sentences naturally readable. Avoid arbitrary manual line breaks, isolated words, oversized line spacing and decorative punctuation used only to fill space.
- Build a coherent, attractive product around real user actions. Avoid generic three-column slogans and repetitive decorative copy.
- A requested Higgsfield or other generated video must be a real video asset, inspected and integrated. Floating images, CSS motion, slideshows and dummy files do not satisfy a video request. Clearly identify unfinished media generation.
- Preserve supplied character identity, proportions, colors and artwork. Follow the user's creative prompt and inspect generated output.
- Use relevant runtime and repository docs, focused code checks, end-to-end browser flows, and direct desktop and mobile visual review. Test counts alone do not prove good design.
- Record corrections in project guidance and regression checks. Complete authorized work and report concrete blockers without long planning explanations.
